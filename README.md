## Description

Complete platform for developing and testing data pipelines with Apache Spark, Apache Hudi and MinIO (S3-compatible). The entire infrastructure runs locally in Docker containers, providing an isolated and reproducible environment.

The platform consists of a Spark Standalone cluster with one master and two workers, all with Apache Hudi 1.1.0 pre-integrated. MinIO acts as S3 storage, with buckets automatically created for Spark History Server events and application data. The Spark History Server is available for querying execution logs.

The environment is orchestrated by Docker Compose. The docker-compose.yml file defines five services: spark-master, spark-worker-1, spark-worker-2, spark-history and minio. All Spark services share the same image built from the Dockerfile, which copies the Hudi JARs generated by Maven.

The start_platform.sh script automates the entire process: it creates necessary directories, runs Maven to generate Hudi JARs and starts containers with docker compose up -d --build. The --build flag ensures the image is built with intelligent caching, rebuilding only changed layers.

After execution, the interfaces are accessible: Spark Master at http://localhost:8083, Workers at 8084 and 8085, History Server at 18080 and MinIO Console at 9001 with username/password minioadmin. Data is persisted in the data/ directory and the spark-logs and data-bureau buckets are automatically created.

To submit jobs, simply run spark-submit inside the spark-master container, using the S3 configurations already predefined in spark-defaults.conf that point to MinIO.

## Structure

```text
spark-hudi-minio-platform/
│
├── docker-compose.yml          # Service orchestration
├── Dockerfile                  # Spark/Hudi image build
├── start_platform.sh           # Main bootstrap script
├── pom.xml                     # Maven dependencies
│
├── conf/                       # Configuration files
│   └── spark/
│       └── spark-defaults.conf # Spark configs
│
├── scripts/                    # Utility scripts
│   └── submit-job.sh           # Example: submit jobs
│
├── target/                     # Generated by Maven
│   └── jars/                   # JARs with Hudi integration
│
└── data/                       # Persistent data
    ├── minio/                  # MinIO data (volumes)
    └── spark-events/           # Spark event logs

```

## Features:

- Spark 4.0.1 in Standalone mode (1 Master + 2 Workers)
- Apache Hudi 1.1.0 pre-integrated in JARs
- MinIO as S3-compatible storage
- Spark History Server for metrics visualization
- Docker Compose with optimized build and intelligent caching

## Get_started

1. Clone the repository

```bash
git clone https://github.com/seu-usuario/spark-hudi-minio-platform.git
cd spark-hudi-minio-platform
```

2. Start the platform

```bash
chmod +x start_platform.sh
./start_platform.sh
```

3. Run the pipeline:

```bash
sudo docker exec spark-master bash -c "/opt/spark/bin/spark-submit /opt/scripts/meu_pipeline.py"
```

4. Access the interfaces

```text
Spark Master	http://localhost:8083	-
Spark Worker 1	http://localhost:8084	-
Spark Worker 2	http://localhost:8085	-
Spark History	http://localhost:18080	-
MinIO Console	http://localhost:9001	minioadmin/minioadmin
```
